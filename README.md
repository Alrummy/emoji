Entry for make.fun's “One Emoji, One Smile” bounty. Entrants send exactly one emoji, the one most likely to make a stranger smile. A judge compares them two at a time and picks the warmer; the emoji that wins the most comparisons takes the reward.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
